# Pixelkey's Delightful Paintings

An original collection of Minecraft paintings by Pixelkey, inspired by the rustic charm of farming, food, and countryside life.

## About

Pixelkey's Delightful Paintings is a standalone painting mod for Minecraft, featuring original artwork created specifically for the game.

The collection brings a little more personality and warmth to Minecraft's walls, with artwork ranging from botanical studies and countryside scenes to food, farming, and everyday life.

Inspired by Vectorwing's Farmer's Delight mod.

## Features

- 14 original paintings.
- Multiple painting sizes and orientations.
- Native Minecraft painting placement.
- Original pixel artwork by Pixelkey.
- No dependency on Farmer's Delight.

## Compatibility

| Component | Version |
|---|---|
| Minecraft | 1.21.1 |
| Mod Loader | NeoForge, Fabric |
| NeoForge | 21.1.x |

**Mod ID:** `pk_delightful_paintings`

## Installation

Choose the version matching your installed mod loader.

### NeoForge
1. Install Minecraft 1.21.1 with NeoForge.
2. Download the NeoForge `.jar` file.
3. Place it in your Minecraft `mods` folder.

### Fabric
1. Install Minecraft 1.21.1 with Fabric Loader.
2. Install Fabric API.
3. Download the Fabric `.jar` file.
4. Place both files in your Minecraft `mods` folder.

Launch the game and enjoy <3

## Building from Source

This project uses Gradle and the NeoForge ModDevGradle plugin.

To build the mod:

```bash
./gradlew build
```

On Windows:

```powershell
.\gradlew.bat build
```

The compiled mod will be located in `build/libs/`.
